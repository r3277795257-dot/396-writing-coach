# 评分红线（scoring_redline）

本文件是 396-writing-coach 评分时的强制红线。评分前必读，规则优先于模型直觉。

## 0. 前提声明（重要）

- **官方（教育部考试院）不公开 396 写作的分档分值细则**，大纲只给宏观要求（内容合理、论证有力、结构严谨、条理清楚、语言流畅）。
- 本文件的分档分值均为**参照管理类联考（199）评分体系按分值比例换算**，属于行业通行做法，**非官方标准**；评分时以**档位描述匹配为准**，换算分值只作参考区间并标注"非官方换算"。

## 1. 分值与档位表（换算参考，非官方）

### 1.1 论证有效性分析（20 分，四类卷）

| 类卷 | 换算参考分 | 档位描述（必须逐条匹配） |
|---|---|---|
| 一类卷 | 约 8-9 分（一类偏上时 9） | 找点准确、分析深刻有力、结构严谨、条理清楚、语言精练流畅 |
| 二类卷 | 约 5-7 分 | 找点较准、分析较有力、结构尚完整、条理较清楚、语句较通顺、有少量语病 |
| 三类卷 | 约 3-5 分 | 有找点有分析、但结构不够完整、语言欠连贯、较多语病、分析缺乏说服力 |
| 四类卷 | 约 0-2 分 | 明显偏离题意、内容空洞、条理不清、语句严重不通 |

换算依据：199 论效 30 分 = 内容 16 + 结构语言 14，四类卷 12-14 / 8-11 / 4-7 / 0-3，按 30→20 等比换算。**标注：非官方换算，仅内部参考。**

### 1.2 论说文（20 分，五类卷）

| 类卷 | 换算参考分 | 档位描述（必须逐条匹配） |
|---|---|---|
| 一类卷 | 17-20 | 立意深刻、中心突出、论证充分、结构完整、行文流畅 |
| 二类卷 | 13-16 | 中心明确、结构较完整、层次较清楚、语句通顺 |
| 三类卷 | 9-12 | 中心基本明确、结构尚完整、语句较通顺、有少量语病 |
| 四类卷 | 5-8 | 中心不太明确、结构不够完整、语句不通顺、语病较多 |
| 五类卷 | 0-4 | 偏离题意、结构残缺、层次混乱、语句严重不通 |

换算依据：199 论说 35 分五类卷（30-35 / 24-29 / 18-23 / 11-17 / 0-10）按 35→20 等比换算，与机构公开换算一致（新东方给出 17-20/13-16/9-12/5-8/0-4）。**标注：非官方换算。**

## 2. 字数红线（真题题干实锤，2021-2026 五套一致）

| 题型 | 要求 | 处理 |
|---|---|---|
| 论证有效性分析 | **600 字左右** | 不足（<500）扣分/降档；超字不扣分，仅提示 |
| 论说文 | **700 字左右** | 不足（<600）扣分/降档；超字不扣分，仅提示 |

- 字数以**汉字**计（标点不计）。
- 明显不足 ⇒ 强制扣分项；严重不足（论效<300、论说<400）不得进二类卷及以上。

## 3. 内部维度权重（仅诊断辅助，非官方）

- 论证有效性分析：内容（找点+分析）55% / 结构 25% / 语言 20%
- 论说文：立意内容 40% / 论证结构 30% / 语言 20% / 规范（题目·字数·错别字）10%
- 禁止宣称这是官方权重；最终分数以档位描述匹配为准。

## 4. 强制扣分项检查（逐项过，命中即扣/降档）

1. **论效文写成驳论文 / 表达自己观点 / 赞同原文**（本质错误，直接降一档以上，最严重可进四类卷）。
2. **论说文跑题 / 立意偏题**（直接进五类卷 0-4 分）。
3. 论效文**找点太少**（<3 个）或**找点错误**（张冠李戴，把没问题的当问题）。
4. 论效文**只指出问题不分析**（"这里有问题"但不说为什么，每点扣分析分）。
5. 论说文**堆砌论据不分析**（只举例不论证）。
6. 漏拟题目：**扣 2 分**（论说文自拟题；论效文也要标题）。
7. **每 3 个错别字扣 1 分**（重复不计，至多扣 2 分）。
8. 字数不足（见第 2 节）。
9. 抄题 / 白卷 / 完全无关 ⇒ 四类卷（论效）/ 五类卷（论说）。
10. 套作痕迹过重且与材料无关（黑名单句命中）。

## 5. 地区校准规则（只提示，不调分；中文写作比英语更保守）

1. 口径：按"目标院校所在省"（396 为统考科目，阅卷由报考单位所在省组织，与公共课一致）。
2. 水旱区是民间经验、非官方；所有相关输出必须附免责声明（见第 6 节）。
3. **中文写作（论效/论说）的水旱区民间数据比英语更稀疏、分歧更大 ⇒ 默认只提示风险，不猜偏水偏旱；只有多源共识强（北京/上海/浙江/江苏/山东为旱）才可给"约一档偏紧"区间提示。**
4. 只给区间提示（最多 1 个档位区间），不改变全国基准分、绝不给具体加减分。
5. 数据不足 / 争议大 / 置信度低 ⇒ 只提示"当前无法验证"或风险。
6. 用户不知道地区 ⇒ 按全国基准评分，提示可补充地区后重新校准。
7. 校准输出顺序：全国基准 → 地区区间（或"无法验证"）→ 依据与置信度 → 备考建议 → 免责声明。
