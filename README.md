# 396-writing-coach · 396经济类联考写作批改教练

一个跑在豆包（Doubao）上的 Skill：批改 396 经济类联考两大写作题型——**论证有效性分析（论效文）**与**论说文**，按档位模拟评分、谬误识别与立意诊断、结合地区"水旱区"民间经验做区间提示、用"学习档案卡"记住你的历史错误并长出个人模板。

> ⚠️ **免责声明（先读）**
> - 396 写作**官方不公开分档分值细则**，本 Skill 的分档分值为参照管理类联考（199）评分体系按分值比例换算，**非官方标准**，仅作练习参考。
> - 所有分数、档位是 AI 做的**模拟评分**，**不构成官方阅卷结果**，正式成绩以考试为准。
> - "水区/旱区/评分偏松偏紧"全部来自考研网络社区的**民间经验汇总**，教育部教育考试院及各省考试院**从未官方划分**水旱区。
> - 地区数据**只做区间提示，不改变全国基准分**；中文写作地区数据比英语更稀疏，默认只提示风险、不猜偏水偏旱。
> - 地区数据更新于 **2026-10-22**，每年阅卷组、大小年都会变化，使用前请自行交叉核实。

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 双题型引擎 | 论效文：谬误识别（10 类谬误）+ 攻击话术诊断；论说文：审题立意 + 论证结构诊断 |
| 输入门槛 Gate | 作文类型 / 题目材料 / 作文原文 三项缺任一不评分，分批追问；地区开跑前必确认 |
| 逐点对照卡 | 论效：材料原文 → 你的攻击 → 判定（找点准/攻击狠/语言稳）→ 标准攻击话术，不用四列表格 |
| 评分红线 | 论效四类卷 / 论说五类卷（非官方换算），字数红线（论效600/论说700，真题题干实锤），10 项强制扣分 |
| 地区校准 | 31 省中文写作水旱民间经验知识库，只给区间提示（≤1 档），默认只提示风险、不猜倾向 |
| 学习档案卡 | 高频错误 Top5（按谬误类/立意类分类）、已掌握项、分数趋势，可复制续接，不依赖平台长期记忆 |
| 个人模板卡 | 从你高分句里抽功能句（主推+2 备选），内置"烂大街句"黑名单防雷同 |
| 隐私脱敏 | 批改前自动把姓名/学校/考号换成占位符，不写进档案 |

## 🚀 安装

**方式一：手动安装**
1. 把整个 `396-writing-coach/` 文件夹放到豆包 Skill 目录下：
   - Windows: `C:\Users\<你>\.doubao\agent_mode\workspace\.user_skills\`
   - macOS: `~/.doubao/agent_mode/workspace/.user_skills/`
2. 重启豆包，新开对话，直接发："帮我批改这篇 396 论效文"并附上材料与作文即可。
3. 第一次使用它会主动问你：报考院校在哪个省、目标分多少——按提示答即可。

**方式二：让豆包自己下载部署**
复制下面这段发给豆包（需你的豆包具备读取该 GitHub 仓库的能力）：
```
请从 GitHub 仓库 r3277795257-dot/396-writing-coach 下载整个 396-writing-coach 文件夹，
安装到你的 Skill 目录（.user_skills 下）。安装完成后告诉我怎么用。
```
（豆包也可直接打开仓库页面的 "Code → Download ZIP"，解压后按方式一放置。）

## 📊 数据来源与置信度

- **评分标准**：396 写作官方不公开分档细则，本 Skill 分档分值为参照管理类联考（199）评分体系按分值比例换算（论效四类卷/论说五类卷），**非官方**；字数红线（论效 600 / 论说 700 字左右）来自 2021-2026 五年真题题干原文。
- **谬误库与立意库**：基于 2021-2026 五年真题归纳（诈骗根治/数字阅读/减负/网络教育/免费服务/食蚁兽/猫鱼/陀螺/春运等）+ 联考写作权威教材通用体系，每条谬误附识别关键词与真题示例。
- **地区倾向**：来自知乎、小红书、B 站、考研机构公开分析等多源民间经验，每条记录标注数据状态（充足/中等/稀疏/数据不足）、置信度、争议标记、是否"只提示不调分"；数据不足省份留空不猜。
- **示例作文**：`examples/` 中的作文为 AI 生成的示例，非真实考生作文、非官方范文。

## 🔒 隐私

- 你的作文只在本次对话里批改，不会被 Skill 另存数据库。
- 姓名、学校、考号、手机号等会在批改前自动替换为占位符，不写进档案卡。
- 学习档案卡是一段可复制的纯文本，由你自己保存、下次粘贴，不依赖云端账户。

## 🔄 更新

- 地区数据：编辑 `references/region_kb.json`，同步更新 `version` 和 `updated` 字段。
- 发现某省数据不准 / 有新反馈：直接改对应省份的 `confidence`、`note`、`evidence`。
- 新真题出现后：向 `fallacy_kb.json` / `liti_kb.json` 补充真题示例，同步递增 `version`。
- 评分规则以最新考纲为准，考纲变动时更新 `references/scoring_redline.md`。
