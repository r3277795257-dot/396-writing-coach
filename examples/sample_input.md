# 典型提交示例（sample_input）

> 以下是"用户提交 → Skill 追问 → 批改"的典型流程示例。作文为 AI 生成的演示文本，非真实考生作文、非官方范文。

## 示例 1：论效文（论证有效性分析）

**用户第一条消息：**

```
帮我批改这篇论效文。

【题目材料】
要减轻中小学生过重的学习负担，还必须加强引导和管理。
首先，我们应引导家长破除"望子成龙"的传统观念，因为这一观念是加重中小学生
学习负担的重要原因之一。千百年来有多少家长都望子成龙，但大部分的孩子还是成了
普通人。如果家长都能正视这一事实，破除"望子成龙"的传统观念，把期望值降低一些，
过重的学习负担马上就减轻了。
其次，我们应该改变"不能输在起跑线上"的观念。众所周知，不能输在起跑线上未必
能赢在终点线上，既然如此，我们又何必纠结于"起跑线"呢？学习就像马拉松，是长期的
过程。马拉松的冠军就不一定是赢在起跑线上的人，如果家长都明白了这个道理，也就不会
给子女加压，孩子们就不会存在过重的学习负担了。
再次，我们应该实施素质教育，废除应试教育。应试教育所带来的课业，无疑加重了中
小学生的学习任务，如果我们全面地实施素质教育就能有效地减轻学生的负担。
最后，如果有关部门再进一步出台更为严格的减轻中小学生学习负担的法规，减负就能
获得成功。

【我的作文】
《减轻负担需要多管齐下》
上述材料认为要减轻中小学生过重的学习负担，必须加强引导和管理。这一论证存在
诸多问题，具体分析如下。
首先，材料认为"望子成龙"是加重学习负担的重要原因。但这一观念由来已久，影响
深远。材料认为破除这一观念负担马上就减轻了，这显然是不对的，因为负担不可能马上就
减轻。
其次，材料用马拉松来类比学习。但学习与马拉松是不同的，学习过程中起跑线的作
用可能更明显，因此这一类比是不恰当的。
最后，材料认为实施素质教育、废除应试教育就能减轻负担，出台法规减负就能成功。
但素质教育与应试教育不能简单对立，出台法规也不一定能保证减负成功。
综上所述，材料的论证存在以偏概全、不当类比等问题，结论难以令人信服。
```

**Skill 行为**：核对硬门槛（作文类型 ✅ / 题目材料 ✅ / 作文原文 ✅）→ 询问目标院校所在省（用户可答"北京"或"不填"）→ 开始批改 → 输出对话精简摘要 + 三件套文件。

## 示例 2：论说文（57 题）

**用户第一条消息：**

```
批改我的论说文。考396，目标院校在北京。

【题目材料】
一种社会事务，往往涉及诸多因素（如春运涉及交通设施、气候条件、民俗文化、经济
环境、科学技术等），所以要依赖诸多部门的通力合作才能处理好。

【我的作文】
《众力并举，方能成事》
春运的顺利运行，离不开交通、气象、公安、志愿者等多方力量的协同。这告诉我们：
处理复杂的社会事务，单靠一方之力远远不够，唯有通力合作才能成事。
首先，社会事务涉及因素众多……（正文略）
综上所述，面对日益复杂的社会事务，我们既要各司其职，更要协同联动，方能行稳致远。
```

**Skill 行为**：判断材料类型（现象评述类）→ 审题立意诊断（立意"通力合作"准确、明确）→ 结构/论证/语言诊断 → 地区校准（北京：约一档偏紧提示，只提示不调分）→ 输出三件套。

## 提交小贴士

1. 论效文最好把**题目材料原文**和作文一起发，找谬误要对着材料来。
2. 作文里别带真实姓名/学校/考号（会自动脱敏，但提前删更省事）。
3. 想获得地区校准就告诉 Skill"目标院校在哪个省"；不说就按全国基准。
